# Images

Place figures used by the notes in this directory. Include a figure with:

```tex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.75\textwidth]{your-image.pdf}
  \caption{A concise and informative caption.}
  \label{fig:your-label}
\end{figure}
```

Prefer vector formats such as PDF, or convert SVG files to PDF. PNG and JPEG
are suitable for photographs and screenshots.
